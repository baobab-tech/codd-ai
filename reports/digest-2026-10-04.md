## Findings (session discoveries)


### access_patterns

- The Canadian Open Data Directory has no API or download. Its 253 org records are a CSV string embedded in the site's SvelteKit JS bundle; the bundle also links two Google Sheets that look like the upstream editing source. _(project:directory; claude 2026-10-04; https://directory.opendatasociety.ca/directory)_
- 42 orgs have no catalog API the probe recognizes. They fall into: documented non-catalog APIs (StatCan WDS, Bank of Canada Valet, GeoNetwork, FRDR, geo.ca), Esri map servers without Hub, static pages linking files, JS apps hiding a backend API, PDF libraries, and pages that aren't data sources. _(project:; claude 2026-10-04; docs/PLAN.md#non-standard-sources)_
- National/federal orgs have the lowest API coverage in the directory (2 of 8): StatCan, Bank of Canada, CMHC, Elections Canada and geo.ca each use bespoke APIs or download pages instead of a catalog platform. _(project:; claude 2026-10-04; pnpm digest (API coverage by org type))_

### bot_blocking

- Données Québec sits behind AWS WAF bot control. HTML pages answer 202 challenge pages under repeated requests and stay challenged even with a browser user agent, while the CKAN API on the same host answers normally. Agents should use the API, not the pages. _(source:ckan:www.donneesquebec.ca; claude 2026-10-04; probes check=root server=awselb/2.0)_

### connectors

- ArcGIS Hub sites expose two catalog endpoints: the OGC search API (/api/search/v1) and a DCAT-US feed (/api/feed/dcat-us/1.1.json). The feed still works on some sites where search is broken. _(connector:arcgis_hub; claude 2026-10-04; src/cli/probe.ts)_

### counts

- Top-level portals with a live catalog API report about 190k datasets in total, against 104,617 in the directory. The gap is mostly orgs reporting NA (Alberta 37.5k, Yukon 3.9k, BC 3.4k, Ontario 3.0k) and stale counts (open.canada.ca 48k live vs 34.8k listed). _(project:; claude 2026-10-04; pnpm digest)_
- CanWIN (U Manitoba) reports 48,773 records via CKAN against 496 in the directory. Needs checking whether these are datasets or harvested or derived records. _(source:ckan:canwin-datahub.ad.umanitoba.ca/data; claude 2026-10-04; https://canwin-datahub.ad.umanitoba.ca/data/api/3/action/package_search?rows=0)_
- open.alberta.ca reports 37,496 CKAN packages; many are publications (PDF reports), not tabular data. _(source:ckan:open.alberta.ca; claude 2026-10-04; https://open.alberta.ca/api/3/action/package_search?rows=0)_

### data_quality

- The directory lists organizations (portals), not datasets. Its 104,617 dataset figure is the sum of self-reported per-org counts, mostly dated 2025-02, with 46 orgs reporting NA. _(project:directory; claude 2026-10-04; data/directory/directory.csv)_
- 45 orgs publish under another portal (Données Québec ×20, Columbia Basin Water Hub ×12, Niagara Open Data ×5, The Data Zone ×3, Region of Durham ×3, HRM, Borealis). Summing directory counts double-counts their datasets. _(project:directory; claude 2026-10-04; orgs.relationship)_
- 12 orgs have a wrong platform label in the directory. Guelph and Thunder Bay are labelled CKAN but run ArcGIS Hub; PEI and Strathcona are labelled Socrata but run Hub; Kingston is labelled Opendatasoft but runs Hub; Yukon is labelled DKAN but runs CKAN. _(project:directory; claude 2026-10-04; open_items kind=platform_mismatch)_
- Shawinigan's directory URL points to the Rouyn-Noranda organization on Données Québec. _(org:ville-de-shawinigan-city-of-shawinigan; claude 2026-10-04; https://www.donneesquebec.ca/recherche/organization/ville-de-rouyn-noranda)_
- Regina's directory URL (open.regina.ca) no longer resolves. The city moved to openregina.ca, a CKAN portal with 1,379 datasets; the directory reports NA. _(org:city-of-regina; claude 2026-10-04; https://openregina.ca/api/3/action/package_search?rows=0)_

### platforms

- ArcGIS Hub is the dominant platform by org count (132 of 253) but small per org (~100 datasets). CKAN serves fewer orgs (47) but holds most datasets, concentrated in federal and provincial portals. _(project:; claude 2026-10-04; pnpm digest)_
- 196 of 253 orgs (77%) expose a catalog API that a standard connector can harvest (CKAN, ArcGIS Hub, Socrata, Opendatasoft, Dataverse, DCAT data.json). Six connectors cover them. _(project:; claude 2026-10-04; pnpm digest)_
- Toronto's catalogue site (open.toronto.ca) is a WordPress front end; the CKAN API lives on a separate host (ckan0.cf.opendata.inter.prod-toronto.ca). Likewise search.open.canada.ca is a search UI over CKAN at open.canada.ca/data. _(org:city-of-toronto; claude 2026-10-04; src/cli/probe.ts API_HOME)_

### reachability

- The Canadian Space Agency portal serves an incomplete TLS certificate chain. Strict HTTP clients (Node, Python requests) fail; browsers succeed by fetching the missing intermediate. _(org:canadian-space-agency; claude 2026-10-04; https://donnees-data.asc-csa.gc.ca)_
- 12 directory links are dead: mostly ArcGIS Hub sites deleted or renamed (Brantford, Hastings County, Okotoks, Orangeville, Calgary Metro Region Board, Edmundston, Saint-Quentin), plus moved city pages (Welland, Chilliwack, Stratford, Cornwall). _(project:; claude 2026-10-04; open_items kind=dead_link)_
- ArcGIS Hub sites can have a broken search API: Quinte West answers 'Site catalog is not configured correctly' (HTTP 400). _(source:arcgis_hub:geodata-quintewest.opendata.arcgis.com; claude 2026-10-04; https://geodata-quintewest.opendata.arcgis.com/api/search/v1/collections/dataset/items?limit=1)_
- open.hamilton.ca returns 403 on API paths. Hamilton's catalog data is served from a McMaster-hosted ArcGIS Hub. _(org:city-of-hamilton; claude 2026-10-04; probes url like %hamilton%)_

### robots

- Robots.txt rarely targets AI crawlers: 7 of 252 hosts name and block them. Six are the Niagara region group (Niagara Open Data, St. Catharines, Fort Erie, Lincoln, Niagara-on-the-Lake, Brock), which block GPTBot, CCBot, Bytespider and Amazonbot. No host names ClaudeBot, and none uses Content-Signal. _(project:; claude 2026-10-04; observations key=robots)_
- All three Dataverse installs (Borealis, Abacus, U of T) disallow all crawlers in robots.txt (the Dataverse default), yet their search API is public and answers. Whether to honour robots.txt for API access is an open decision. _(platform:dataverse; claude 2026-10-04; https://borealisdata.ca/robots.txt)_
